\begin{abstract}
Cooperative multi-agent reinforcement learning (MARL) requires agents to coordinate under partial observability via communication. Most existing methods optimize only the communication \textit{topology} (who talks to whom) while assuming unlimited per-message bandwidth---an unrealistic assumption in real deployments such as drone swarms and robot fleets. We present \textbf{ExpoComm-B}, which jointly optimizes topology and bandwidth by integrating the Bandwidth-constrained Variational Message Encoding (BVME) bottleneck into the ExpoComm sparse exponential-graph communication framework. Each inter-agent message is treated as a sample from a learned Gaussian posterior regularized via KL divergence, providing tunable control over per-message information capacity while preserving ExpoComm's $O(\log N)$ connectivity. We evaluate on two benchmarks. On \textbf{MAgent Battle} (81 vs.\ 81 agents), ExpoComm-B ($\sigma_0{=}0.05$) reduces average enemy survivors from 72.4 (QMIX baseline) to 3.6. On \textbf{MPE Simple Spread} (3 agents, 500k steps), ExpoComm-B achieves a final test return of $-8.16$, compared to $-26.60$ (QMIX), $-27.11$ (ExpoComm), and $-28.90$ (BVME-only). Ablation studies show that performance is stable across five orders of KL weight ($\lambda$) and that an 8$\times$ message compression causes only a 0.06-point drop in return.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Cooperative multi-agent systems must coordinate decisions across distributed agents that observe only local state. Graph Neural Networks (GNNs) have become the standard architecture for modelling agent interactions: agents are nodes, communication links are edges. The dominant paradigm---Centralized Training, Decentralized Execution (CTDE)---designs or learns communication graphs during training.

However, most methods make two simplifying assumptions: (1)~every agent can communicate with every other agent (fully connected, $O(N^2)$ overhead), and (2)~messages are full-dimensional hidden-state vectors with no bandwidth constraint. Both assumptions fail in real deployments where agents communicate over wireless channels with limited capacity.

Recent work addresses each limitation in isolation. \textbf{ExpoComm}~\cite{expocomm} (ICLR 2025) learns sparse exponential-graph topologies with $O(\log N)$ connections and $O(\log N)$ diameter. \textbf{BVME}~\cite{bvme} (AAMAS 2026) applies a variational information bottleneck to compress messages, achieving 67--83\% compression on SMACv2 with negligible loss. Neither paper addresses both problems simultaneously.

We propose \textbf{ExpoComm-B}, which integrates BVME compression into ExpoComm's pipeline. Our contributions are:
\begin{enumerate}[noitemsep,topsep=2pt]
\item A unified architecture combining exponential-graph topology selection with variational message compression, trained via a combined TD + auxiliary state-prediction + KL loss.
\item Empirical evaluation on MAgent Battle (large-scale, 81 agents) and MPE Simple Spread (continuous navigation, 3 agents).
\item Ablation studies over KL weight $\lambda \in \{0.01,0.1,1.0,5.0,10.0\}$ and compression ratio $r \in \{1.0, 0.5, 0.25, 0.125\}$.
\end{enumerate}

\section{Related Work}
\label{sec:related}

\paragraph{Sparse Communication Topologies.}
ExpoComm~\cite{expocomm} uses exponential graph topologies inspired by distributed computing. In one-peer mode each agent at timestep $t$ sends exactly one message to neighbor $(i + 2^{t \bmod k}) \bmod N$, where $k = \lfloor\log_2 N\rfloor + 1$. TGCNet~\cite{tgcnet} learns directed graphs dynamically but does not constrain bandwidth. DG-MAPPO~\cite{dgmappo} enforces communication budgets via graph attention but requires dense attention computation.

\paragraph{Bandwidth-Constrained Communication.}
BVME~\cite{bvme} encodes each message $m$ as $z \sim \mathcal{N}(\mu(m), \sigma^2(m))$, regularized against prior $\mathcal{N}(0,\sigma_0^2 I)$. The prior scale $\sigma_0$ controls per-dimension information capacity. Larger $\sigma_0$ relaxes the bottleneck. Our work applies BVME inside ExpoComm's sparse topology.

\paragraph{GNNs and MARL.}
Factored value functions via graph diffusion~\cite{factored} and mean-field control on sparse graphs~\cite{mfc} provide theoretical grounding for GNN-based policies. Our work contributes an empirical demonstration that joint optimization of \textit{topology} and \textit{bandwidth} outperforms either alone.

\section{Background}
\label{sec:background}

\paragraph{Dec-POMDP.} We model the cooperative problem as a Decentralized POMDP $\langle N, S, \{A_i\}, \{O_i\}, T, R, \gamma \rangle$. All $N$ agents share a global reward $R$ but each agent $i$ observes only $o_i \in O_i$.

\paragraph{QMIX.} Under CTDE, QMIX decomposes $Q_\text{tot}$ into per-agent utilities via a monotonic mixing network: $\partial Q_\text{tot}/\partial Q_i \geq 0$, enabling consistent greedy action selection during decentralized execution.

\paragraph{Exponential Topology.} For agent $i$ with connectivity parameter $k = \lfloor\log_2 N\rfloor + 1$:
\begin{equation}
\mathcal{N}(i) = \{(i + 2^j) \bmod N \mid j = 0,\ldots,k{-}1\}
\end{equation}
In one-peer mode, agent $i$ communicates with exactly $\mathcal{N}(i)[t \bmod k]$ at step $t$.

\paragraph{BVME Bottleneck.} Given raw message $m \in \mathbb{R}^d$, BVME learns $\mu = W_\mu m + b_\mu$ and $\log\sigma^2 = \text{clamp}(W_\sigma m + b_\sigma, [-5,3])$. The compressed message is $z = \mu + \sigma \odot \epsilon$, $\epsilon \sim \mathcal{N}(0,I)$. The KL regularization loss is:
\begin{equation}
\mathcal{L}_\text{KL} = \frac{1}{2d}\sum_{j=1}^d \left[\frac{\sigma_j^2 + \mu_j^2}{\sigma_0^2} - \log\frac{\sigma_j^2}{\sigma_0^2} - 1\right]
\end{equation}

\section{Method: ExpoComm-B}
\label{sec:method}

\subsection{Architecture}

ExpoComm-B inserts the BVME bottleneck after ExpoComm's message aggregation step and before the Q-network. For agent $i$ at timestep $t$:

\begin{enumerate}[noitemsep,topsep=2pt]
\item \textbf{Observation encoding:} $x_i = \text{ReLU}(\text{FC}_1(o_i^t))$
\item \textbf{Hidden state:} $h_i^t = \text{GRU}(x_i,\, h_i^{t-1})$
\item \textbf{Sparse comm.:} receive message from one exponential-graph neighbor; process through message-GRU to produce raw message $m_i^t$
\item \textbf{BVME compression:} $m_i^t \to (\mu,\sigma) \to z_i^t \sim \mathcal{N}(\mu,\text{diag}(\sigma^2))$
\item \textbf{Action selection:} $Q_i = \text{FC}_2([h_i^t;\, z_i^t])$
\item \textbf{Auxiliary prediction:} $\hat{s} = \text{PredictNet}(z_i^t)$ (predicts global state; grounding signal)
\end{enumerate}

During training, the sampled $z$ (not $\mu$) feeds into the Q-network so that the KL penalty directly constrains decision-relevant representations. During evaluation, $z = \mu$ for stability.

\subsection{Training Objective}

\begin{equation}
\mathcal{L}_\text{total} = \mathcal{L}_\text{TD} + \alpha\cdot\mathcal{L}_\text{aux} + \lambda\cdot\mathcal{L}_\text{KL}
\end{equation}

$\mathcal{L}_\text{TD}$: QMIX temporal-difference loss. $\mathcal{L}_\text{aux}$: MSE between $\hat{s}$ and global state (from ExpoComm). $\mathcal{L}_\text{KL}$: BVME bandwidth regularization (Eq.~2). We use $\alpha = 1.0$ throughout.

\subsection{Implementation}

We build on the open-source ExpoComm codebase (Apache 2.0) using the EPyMARL framework. Since BVME has no public code, we implement the full module from the paper's equations. Three new components: \texttt{BVMEModule} (encoder + KL computation), \texttt{ExpoCommBAgent} (extends one-peer agent), \texttt{BVMEQLearner} (three-term loss).

\section{Experiments}
\label{sec:experiments}

\subsection{Environments and Setup}

\textbf{MAgent Battle.} A $45\times45$ grid, 81 blue (learning) vs.\ 81 red (pretrained) agents. Each agent has a $7\times7$ local view. Episodes up to 200 steps. Training target: 5,050,000 timesteps. Run on the Rice NOTS HPC cluster (commons partition, 24-hour SLURM limit). Seed: 123.

\textbf{MPE Simple Spread.} 3 cooperative agents must cover 3 landmarks while avoiding collisions. Episodes: 25 steps. Training target: 500,000 timesteps (all runs completed). NOTS CPU nodes. Seed: 0. PettingZoo v1.14 (\texttt{simple\_spread\_v2}).

All runs use QMIX as value-decomposition backbone, learning rate $5\times10^{-4}$, $\gamma=0.99$, hidden dim 64, $\alpha=1.0$.

\section{Discussion}
\label{sec:discussion}

\paragraph{MPE: Why does ExpoComm-B outperform by such a large margin?}
All three baselines plateau in the $[-27, -29]$ range. ExpoComm-B converges to $-8.16$---a gap of ${\sim}19$ points. The baselines span different topology/compression choices (QMIX: full-comm/uncompressed; ExpoComm: sparse/uncompressed; BVME-only: full-comm/compressed), yet all perform similarly. This suggests that in the 3-agent MPE task, neither topology alone nor compression alone is the critical factor. The joint optimization in ExpoComm-B---where the variational bottleneck learns to compress \textit{only} the most coordination-relevant features along the sparse topology---appears to provide a qualitatively different learning signal.

\paragraph{MAgent: $\sigma_0=0.05$ is a strong outlier.}
The $\sigma_0=0.05$ result (3.6 survivors, return $-0.407$) is dramatically better than all other settings. At $\sigma_0=0.05$, the KL loss is 0.35 (nearly zero), meaning the bottleneck imposes almost no compression---messages are essentially uncompressed. This suggests the \textit{topology} (ExpoComm's sparse graph) is the primary driver of performance, with the bottleneck beneficial only when not over-tightened.

\paragraph{Compression ratio is robust.}
Across 8$\times$ reduction in message dimension (64$\to$8), performance changes by only 0.06 on MPE (Table~\ref{tab:cr_ablation}), from $-8.16$ to $-8.22$. This is a practically important result: ExpoComm-B can operate at a fraction of the communication bandwidth with negligible performance cost.

\paragraph{Limitations.}
\textbf{(1) Single seed.} All experiments used a single seed (123 for MAgent, 0 for MPE). Results may not be statistically representative.
\textbf{(2) MAgent training incomplete.} No MAgent run reached the 5.05M target due to the 24-hour SLURM limit. Different methods reached different step counts (66--98\%), making direct comparisons imprecise.
\textbf{(3) No raw MAgent logs.} The MAgent baseline and $\sigma_0$ ablation results in Section~5.2--5.3 come from a compiled results document (Ansh Dabral's runs); raw log files are not retained in the repository for those experiments.

\section{Conclusion}
\label{sec:conclusion}

We presented ExpoComm-B, which jointly optimizes sparse communication topology (who to communicate with) and message bandwidth (how much information to transmit) in cooperative MARL. On MPE Simple Spread, ExpoComm-B achieves a final test return of $-8.16$ vs.\ $-26.60$ to $-28.90$ for three single-axis baselines. On MAgent Battle, the $\sigma_0=0.05$ variant reduces enemy survivors from 72.4 (QMIX) to 3.6. Ablation studies on MPE show robustness to the KL weight ($\lambda$ varies across five decades with $<0.42$ point change) and the compression ratio (8$\times$ compression with $<0.06$ point change). These results demonstrate that jointly optimizing topology and bandwidth yields significantly better coordination than optimizing either dimension in isolation.
